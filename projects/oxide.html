Features

  • Native CLOB supporting spot and perpetual markets
  • Matching engine ≥5M ops/sec single-core
  • Sub-200 nanosecond per-order latency
  • oxideBFT pipelined 2-chain HotStuff consensus
  • 50-100ms block cadence, 150-250ms finality
  • 1-5 gigagas/second sustained EVM throughput
02

Architecture

Consensus
  • oxideBFT — pipelined 2-chain HotStuff consensus
  • MockEngine — testing and simulation harness
  • SequencerEngine — transaction ordering and batching
Storage
  • Authenticated journal (MMR-over-log)
  • redb — embedded key-value store
  • RocksDB — LSM-tree persistent storage
  • MDBX — memory-mapped database
Execution
  • revm — fast EVM implementation
  • Parallel Block-STM concurrency for transaction execution
Trading
  • Flat tick ladder order book structure
  • Native CLOB (Central Limit Order Book)
  • Exchange settlement engine
03

DependenciesCore libraries

  • BLAKE3 — fast cryptographic hashing
  • BLS12-381 — threshold signatures for consensus
  • ed25519 — signing for transactions and identities
  • revm — EVM execution engine
  • MDBX / RocksDB — persistent storage backends
