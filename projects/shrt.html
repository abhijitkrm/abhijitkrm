Features

  • fasthttp zero-allocation HTTP engine with pipelining
  • Custom append-only log with 256-shard in-memory index
  • Batched writes and fsync every 5ms
  • sonic SIMD JSON serialization
  • 8-character codes (instance prefix + 7 random base62)
  • SO_REUSEPORT multi-instance kernel load balancing
02

Architecture

Storage Backends
  • In-process AOF with 256-shard in-memory index
  • Dragonfly for distributed caching
  • Redis for traditional key-value storage
  • Pebble LSM-tree storage
  • RocksDB embedded database
Multi-Process Scaling
  • N processes sharing one port via SO_REUSEPORT
  • Per-instance log shards, linear write scaling
  • OS page cache within 5ms
  • fsync every 500ms for durability
03

Implementations

  • Go — Primary implementation with fasthttp
  • Rust — High-performance alternative
  • C++20 — Low-level systems implementation
  • Java — JVM-based version
  • TypeScript — Node.js implementation
