evm-hft

Cosmos-EVM port optimized for HFT trading. Custom HotStuff consensus engine with ~200ms block time, native CLOB module with parallel matching, trading mempool with P2P gossip, and EVM precompiles for order execution.

Features

  • Pipelined 3-chain HotStuff consensus replacing CometBFT
  • Native x/clob module with FIFO matching engine
  • CLOB precompile for Solidity order execution
  • Trading mempool with parallel P2P gossip
  • Parallel per-pair matching with lane isolation
  • Gasless price-feed precompile via vote extensions
  • Reentrancy guards for deposit/withdraw
  • WAL persistence with crash recovery
02

Architecture

Consensus
  • 3-chain pipelined HotStuff (Aptos/Diem lineage)
  • Leader-centric O(n) gossip vs Tendermint's O(n²)
  • ABCI++ interface mapping (PrepareProposal, ProcessProposal, ExtendVote)
  • Pacemaker with exponential backoff (capped at 8x)
  • Vote keeper with quorum tracking (strict >2/3)
CLOB Module
  • In-memory B-tree order book with price-time priority
  • Parallel lane execution with journal-based merge
  • Settlement accumulator for atomic balance updates
  • Tick-size validation with configurable precision
  • Market maker bond system
Trading Mempool
  • Batch state machine with verified order tracking
  • Ed25519 signature cache with eviction budget
  • Rate limiting per trader/pair
  • P2P gossip via trading reactor
  • Preconf support for sub-block latency
EVM Integration
  • CLOB precompile: PlaceLimitOrder, PlaceMarketOrder, CancelOrder
  • Deposit/Withdraw with reentrancy protection
  • Query methods: GetOrderBook, GetOrder, GetUserOrders
  • Price precompile at 0x0...0888 (vote extension primary)
  • Gasless price writes via ante fee-waiver
